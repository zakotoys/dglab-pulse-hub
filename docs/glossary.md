# dglab-pulse-hub 术语表（Glossary）

## 使用规则

- 本表中的“规范名称”是产品、文档、API、测试和 UI 应优先使用的概念。
- “别名/旧称”仅用于理解外部资料，不建议作为新接口或新文档的主名称。
- “不要混用”用于容易造成格式、层级或安全误解的词。
- 未在本表定义的协议字段，不应根据名称自行推断语义；应引用格式研究或对应版本资料。

## 领域对象

| 规范名称 | 英文/代码名 | 定义 | 别名/不要混用 |
| --- | --- | --- | --- |
| 脉冲文件 | `.pulse` | DG-LAB 4 App 使用的明文分享/编辑文件格式，是本项目唯一的规范用户波形输入输出格式。 | 不要与 dglab-kit JSON、BLE 包或 Socket JSON 混称为 `.pulse`。 |
| Pulse | `Pulse` | `.pulse` 文件被解析后的结构化波形文档，包含全局设置、section、脉冲元和曲线点。 | 不要把 Pulse 仅理解为原始文本字符串。 |
| 波形流 | `WaveformStream` | 从 Pulse 展开的有序波形序列，是预览、播放模拟、点位信息和图像导出的基础。 | 不要把 stream 当作第二种用户文件格式；不要与网络 stream 混用。 |
| 元数据 | `Metadata` | 描述文件、Pulse、section、stream 或点位的上下文信息。 | 不是一个固定且只有一层的字段对象。 |
| 文件级元数据 | `FileMetadata` | 文件名称/路径（适用时）、大小、格式、版本、来源、处理状态和原始标识等信息。 | 不等同于 Pulse 内容。 |
| Pulse 级元数据 | `PulseMetadata` | 全局设置、section 数量、逻辑时长和整体诊断等信息。 | 不要与文件大小、文件格式等文件级属性混合。 |
| Section 元数据 | `SectionMetadata` | section 的启用状态、频率设置、模式、目标/实际时长和脉冲元数量等信息。 | section 是 Pulse 的子结构，不是独立文件。 |
| Stream 元数据 | `StreamMetadata` | stream 点数、总时长、时间粒度、频率/强度统计和展开警告等信息。 | 不等同于原始 `.pulse` 字段。 |
| 点位元数据 | `PointMetadata` | stream 点位的时间、持续时间、频率、强度、来源和插值状态等信息。 | 不要把显示坐标当作波形数值。 |

## `.pulse` 结构

| 规范名称 | 英文/代码名 | 定义 | 别名/不要混用 |
| --- | --- | --- | --- |
| 全局设置 | `global settings` | `.pulse` 等号左侧的全局播放/编辑参数集合。 | 不要把这些参数当作 BLE 帧字节。 |
| Section | `section` | Pulse 中的一段波形配置，由 section 设置和脉冲元组成，可有启用状态。 | 不要与 stream 的时间片段或文件分段混用。 |
| 脉冲元 | `pulse element` | section 中按一定次数重复的基本波形单元，包含频率定义、持续时间和强度曲线。 | “脉冲”“波形点”都不足以替代该层级。 |
| 曲线点 | `control point` | 脉冲元强度曲线中的一个有序点，包含强度和锚点/自动点状态。 | 不等同于展开后的 stream sample。 |
| 锚点 | `anchor point` | 用户固定的曲线点；自动重算时其值保持不变。 | 不要与图表视觉上的最高点混用。 |
| 自动点 | `interpolated point` | 根据有效约束自动计算得到的曲线点，可在相关锚点或边界变化时重算。 | 不等同于原始锚点，也不代表数据不可靠。 |
| 频率定义 | `frequency definition` | section/脉冲元中描述频率固定或变化方式的参数集合。 | 不要只用“频率索引”代替完整定义。 |
| 频率模式 | `frequency mode` | 控制频率在 section、脉冲元内如何保持或变化的模式值。 | 模式编号与显示名称可能随版本变化，不能脱离版本使用。 |
| 时长定义 | `duration definition` | 描述 section 或脉冲元目标持续时间的参数。 | 目标时长不一定等于重复取整后的实际时长。 |
| 目标时长 | `target duration` | 用户或文件表达的期望持续时间。 | 不要与实际输出时长混用。 |
| 实际时长 | `effective duration` | 根据脉冲元重复次数、时间粒度或升级规则计算出的实际持续时间。 | 不一定等于目标时长。 |
| 休息时间 | `rest time` | 连续 section/波形单元之间的暂停时间。 | 不要作为 section 内脉冲元时长。 |
| 播放速度 | `playback speed` | Pulse/播放器层的播放速度参数。 | 不等同于频率，也不等同于设备传输速率。 |
| 频率平衡 | `frequency balance` | `.pulse` 或播放器层可能携带的频率感受调节参数；精确语义依赖目标版本。 | 未确认版本时不得擅自解释为物理频率。 |
| 强度曲线 | `intensity curve` | 脉冲元内随时间变化的强度点集合。 | 不等同于设备通道的绝对强度控制。 |

## 数值与派生概念

| 规范名称 | 英文/代码名 | 定义 | 别名/不要混用 |
| --- | --- | --- | --- |
| 强度 | `intensity` | `.pulse` 曲线中描述单个时间位置刺激强弱的数值，具体范围由目标版本约束。 | 不等同于人体安全等级或设备通道设置值。 |
| 频率 | `frequency` | Pulse/stream 中描述脉冲重复特征的数值或索引映射结果。 | 频率索引不是物理单位；展示时应说明语义。 |
| 频率索引 | `frequency index` | `.pulse` 中用于选择/表达频率的版本相关索引。 | 不要直接当作 Hz 或周期。 |
| 时长索引 | `duration index` | `.pulse` 中用于选择/表达持续时间的版本相关索引。 | 不要直接当作毫秒，除非目标版本映射已确定。 |
| 归一化位置 | `normalized position` | 插值区间内的位置 `x`，范围为 `[0, 1]`。 | 不要与原始时间戳混用。 |
| 二次插值函数 | `quadratic interpolation` | 本项目指定的曲线函数 `f(x) = 1 - (1 - x) ** 2`，用于约束下的曲线补点或重算。 | 不要替换为线性、三次或其他衰减函数。 |
| 展开 | `expansion` | 将 Pulse 的 section、脉冲元和曲线点转换为有序 WaveformStream 的过程。 | 不等同于导出为设备数据包。 |
| Stream 点位 | `stream sample` | WaveformStream 中带时间、持续时间、频率、强度和来源的有序项。 | 不等同于 `.pulse` 原始曲线点。 |

## 格式、版本与诊断

| 规范名称 | 英文/代码名 | 定义 | 别名/不要混用 |
| --- | --- | --- | --- |
| QR 封装 | `QR envelope` | 以 `#DGLAB-PULSE#` 前缀承载 `.pulse` 分享内容的编码封装。 | 不是独立的波形模型或长期存档格式。 |
| 格式 | `format` | 内容的序列化表示方式，例如 `.pulse` 明文或 QR 封装。 | 不要与版本、方言、传输协议混用。 |
| 支持画像 | `format profile` | 本项目依据官方语义、样例和互操作结果明确支持的一组 `.pulse` 语法/语义规则。 | 不等同于官方文件版本，也不等同于规则版本。 |
| 版本 | `version` | 外部格式明确提供或经可靠证据识别的语法/语义版本。当前 corpus 文件没有显式版本字段。 | 不得从文件名或 App 名称推断；不等同于 App、主机或 Socket 版本。 |
| 方言 | `dialect` | 在相同表面前缀下具有不同字段语义或约定的格式变体。 | 未确认方言不能静默转换。 |
| 规则版本 | `rule version` | 本项目解析、校验、展开、插值或升级规则的版本。 | 不等同于文件版本或支持画像。 |
| 证据等级 | `evidence level` | 某项字段语义或规则的依据类别，例如官方语义、语料观察、社区推断或未验证。 | 不代表诊断 severity，也不能把推断提升为官方事实。 |
| 语义等价 | `semantic equivalence` | 两份文件经解析后表达相同的受支持 Pulse 语义，即使文本格式化不同。 | 不等同于字节级相同或保留所有未知字段。 |
| 校验 | `validation` | 对输入或修改结果执行识别、结构、范围和语义检查的过程。 | 不等同于自动修复。 |
| 诊断 | `diagnostic` | 描述错误、警告、信息或建议的结构化结果。 | UI 文案不是诊断 code。 |
| 阻断错误 | `error` | 使当前操作无法安全完成或不能生成可信输出的问题。 | 不应被降级为普通提示。 |
| 警告 | `warning` | 操作可以继续，但存在兼容性、舍入、补点或信息损失风险。 | 不等同于合法性通过。 |
| 变更记录 | `change record` | 记录升级、插值、编辑或格式化造成的语义变化。 | 不等同于撤销栈本身。 |

## 产品与运行环境

| 规范名称 | 英文/代码名 | 定义 | 别名/不要混用 |
| --- | --- | --- | --- |
| 播放模拟 | `preview playback` | 按 WaveformStream 时间顺序在本地/浏览器中展示或计时播放的预览行为。 | 不触发设备输出；不要简称为“设备播放”。 |
| 设备播放 | `device playback` | 通过后续设备 adapter 向 DG-LAB 设备发送波形的行为。当前不属于核心文件处理范围。 | 不得由导入或预览模拟隐式触发。 |
| 单文件任务 | `single-file task` | 针对一个输入文件执行导入、校验、升级、导出或预览的任务。 | 不等同于 UI 页面。 |
| 批量任务 | `batch task` | 对多个输入文件执行相同或相关操作并聚合结果的任务。 | 单文件失败不应使其他文件结果失效。 |
| 核心层 | `core` | 不依赖 Electron、DOM、Nginx 或具体传输实现的领域和应用能力。 | 不要将 UI helper 称为核心领域逻辑。 |
| 适配器 | `adapter` | 将文件系统、HTTP、QR、图像、IPC 或设备能力接入应用用例的边界。 | 适配器不应重新实现领域规则。 |
| Electron 应用 | `Electron app` | 面向普通用户的本地桌面交付形态，可离线完成基础文件处理。 | renderer 不是核心领域层。 |
| Web 服务 | `Web` | 通过浏览器访问 Node.js API 和静态 Web 的可自部署服务端交付形态。 | 不等同于 Nginx 本身。 |
| Nginx | `Nginx` | Web 部署中的静态资源服务与反向代理组件。 | 不承载 Pulse 解析、校验或业务逻辑。 |
| Docker Compose 部署包 | `Compose deployment` | 组合 Web、Node.js API、Nginx 和必要运行资源的可部署交付物。 | 不等同于单一 Nginx 镜像。 |

## 安全与使用边界

| 规范名称 | 英文/代码名 | 定义 | 别名/不要混用 |
| --- | --- | --- | --- |
| 文件合法性 | `file validity` | 文件能否按受支持规则解析、校验并展开。 | 不代表人体安全、医疗有效或设备一定接受。 |
| 使用安全 | `usage safety` | 与人体、设备和使用场景相关的安全判断，超出本项目文件合法性能力。 | 不得由合法性状态推导。 |
| 原始快照 | `source snapshot` | 导入后保留的不可变原始字节，用于未修改导出、对比、恢复和追踪。 | 不等同于自动备份或覆盖原文件。 |
| 临时文件 | `temporary file` | Web 服务或本地任务期间为处理而创建、具有明确生命周期的中间文件。 | 保存策略必须显式定义。 |
